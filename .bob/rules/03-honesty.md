# Honesty (lessons from rehearsals)

- Only claim what evidence shows (a test output or a `governance/evidence.jsonl` line). A server restart isn't a test.
- `/review` and subagent findings can be invented. Check each one against the real files first.
- You can't click the UI (recording, restarts, approvals, Wi-Fi). Say so in one line and stop.
- Disclose every tool used in the README "Tools used" section.
- Attribution in README/pitch: scope and architecture decisions belong to the project lead; Bob is the primary
  implementation tool; Claude = orchestration/validation, ChatGPT = strategy/review support (only if used). Never say
  an AI owns the project, and never say the human hand-wrote code that Bob wrote.
